# Mago Creates ✨

My personal portfolio website, built from scratch to showcase my projects,
experience, and work as a software developer.

🌐 **Live site:** https://magorincon.com

## About

I built this portfolio as a place to share the projects I've worked on,
including software development, machine learning, mobile applications,
and game development.

The website was designed and developed from scratch with a focus on a
simple, responsive interface and a style that feels personal to me.

## Built With

- HTML
- CSS
- JavaScript
- GitHub Pages

## Features

- Responsive design for desktop and mobile
- Interactive experience tabs
- Featured project carousel
- Project gallery
- Custom mobile navigation
- Links to project repositories and demos
- Downloadable resume

## Running Locally

Clone the repository:

git clone https://github.com/Mago-RM/MagoCreates.git

Then open `index.html` in your browser or run it with a local development
server such as VS Code Live Server.
